## Execution

- Implement each vertical slice and don move to the next if isn't not fully implemented and tested.
- A task is done only when its acceptance criteria are met and verified (test passes, endpoint returns X, file exists — as written).

## Tracking

- The moment a task's acceptance criteria are met, mark it `- [x]` in `tasks.md`. Don't batch this to the end - update per task.
- `tasks.md` is the live source of truth; keep it accurate so progress is readable from the file at any point.
- If a task can't meet its criteria, leave it `- [ ]`, note the blocker under **Open**, and don't mark it done.
